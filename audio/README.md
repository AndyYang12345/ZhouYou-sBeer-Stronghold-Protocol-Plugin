# audio/ — 音乐放这里

本目录**不分发任何音频**。请自备音乐文件，理由：

- 音乐有各自的版权与授权，不应随代码仓库分发；
- 仓库保持轻量，便于别人 clone。

## 用法

1. 把你的音乐放到这里，例如 `audio/friends-wine.m4a`
2. 部署时让游戏能访问到它（`tools/game-patch.sh` 会提示路径）
3. 在 `<html data-sp-spin-music="...">` 里写上路径

## 参考实现的参数（供对照）

原始参考用的是一首 187 秒的曲子，AAC 96 kbps（约 2.2 MiB），带 0.35 秒淡入与 2 秒淡出。
本项目不依赖任何具体曲子 —— 换成你自己的即可。
